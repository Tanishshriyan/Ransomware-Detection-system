3-Phase Protection Pipeline

Real process telemetry moves through three strict phases: detect, score, and automatic containment.

1

Detect

Live process and file-system events are captured from the host machine in real time.

2

Score

Behavioral indicators and ML confidence are converted into a normalized 0-100 threat score.

3

Terminate + Notify

Any process at score 60 or higher is terminated immediately. Notification is sent only after the action result.
